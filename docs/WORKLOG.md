# WORKLOG — what changed, where, why, when, which commit

Append-only. One entry per real commit, generated by
`node scripts/log-change.cjs` (never hand-typed) so the hash, files and UTC
time cannot drift from reality. Newest entries go at the end. A commit that
only appends to this file is exempt from needing an entry.

```
node scripts/log-change.cjs --layer L2 --why "why it had to change" \
  --evidence "tests 11/11, OVERLAY_OK, event living-haul-cargo-adopted"
node scripts/log-change.cjs --check     # format + duplicate audit
```

Layers: `L1` stock EveJS patch, `L2` co-op overlay, `L3` new mechanism,
`DOCS`, `TEST`, `OPS`. Full rules: `docs/UPSTREAM_PATCH_SERIES.md`,
`docs/DEVELOPMENT_DOCTRINE.md`.
